# Bienvenue sur le Magasin d'Applications

> Le **Magasin d'Applications (MagApp)** est votre point d'entrée unique vers les outils numériques de la Ville : logiciels métiers, messagerie, plateformes RH, applications de gestion… Tout est regroupé ici, par catégorie, sans avoir à retenir une liste d'adresses.

---

## Trouver et lancer une application

- **Recherche** : la barre en haut de page retrouve une application par son nom.
- **Catégories** : les applications sont classées (Administratif, Ressources Humaines, CMS, Sport et culture…).
- **Lancer** : cliquez sur une application pour l'ouvrir dans un nouvel onglet.
- **Favoris** : cliquez sur le **cœur ⭐** pour épingler une application et la retrouver plus vite.
- **Documentation** : certaines applications proposent **« Consulter la documentation »** (guides PDF, vidéos, liens utiles).
- **Maintenance** : si une application est en maintenance planifiée, un bandeau apparaît directement sur sa tuile avec les horaires.

---

## Mes outils DSI

Le bouton **« Mes outils DSI »** regroupe des services transverses (la liste évolue régulièrement) :

- **Outils PDF** — tout se fait en ligne, sans installer de logiciel :
  - **Fusionner** plusieurs PDF/images en un seul document ;
  - **Découper / réorganiser** (extraire, réordonner, tourner des pages) ;
  - **Réduire la taille** (compression) ;
  - **Convertir en images** (PNG/JPEG) avec choix de la **qualité (150 → 600 dpi)** et, pour les PNG, option **fond blanc transparent** ;
  - **Filigrane** (texte ou logo), **numérotation** de pages ;
  - **OCR** : rendre cherchable un PDF scanné ;
  - **Comparer** deux PDF, **réparer** un PDF abîmé ;
  - **Protéger par mot de passe** : chiffrement AES-256 (le mot de passe est exigé pour ouvrir le document) ;
  - **Modifier un PDF** : sélectionner les objets réels (textes, graphiques), les déplacer ou les supprimer, éditer le texte, ajouter textes, formes, surlignage, zones blanches, images, gomme ;
  - **Publipostage PDF** : fusionner un modèle PDF avec un fichier Excel (placez les variables, générez un PDF unique ou un fichier par ligne, au format ZIP).
- **PDFothèque** : tous les documents que vous enregistrez depuis les outils PDF. Recherche par nom, aperçu, téléchargement, **envoi par mail** et suppression. Les documents y sont **conservés 6 mois** puis supprimés automatiquement.
- **Rencontres annuelles** : réunions et demandes budgétaires (selon vos droits).
- **Transcript manager** : comptes rendus de réunion et résumés assistés par IA.
- **Parapheur** : signer et suivre vos documents électroniques.
- **Mes abonnements** : suivre l'état de vos services.
- **Déclarer un incident** / **Faire une demande** : contacter la DSI (voir ci-dessous).

> 💡 Les résultats des outils PDF peuvent être **enregistrés dans la PDFothèque** (personnelle) pour être retrouvés plus tard.

## Déclarer un incident ou faire une demande

Deux parcours distincts, accessibles depuis « Mes outils DSI » :

- **Déclarer un incident** : quelque chose ne fonctionne plus ou fonctionne mal (application en panne, poste bloqué, imprimante en erreur…). Décrivez le problème, la DSI est notifiée immédiatement.
- **Faire une demande** : besoin d'un nouveau matériel, d'un accès, d'une évolution… Certaines demandes suivent un parcours guidé (formulaire dédié), d'autres passent par une demande libre.

Vous suivez l'avancement de vos incidents et demandes dans **« Mes tickets »**, en haut de page.

---

## Notifications et nouveautés

À chaque évolution importante de MagApp, un message **« Nouveautés »** s'affiche à la connexion pour présenter les derniers ajouts. Vous pouvez le revoir à tout moment via l'historique des versions.

---

## Connexion

MagApp utilise vos **identifiants de session Windows (AD)**, les mêmes que sur votre poste. Cochez **« Se souvenir de moi »** pour éviter de ressaisir votre mot de passe à chaque ouverture.

---

## Besoin d'aide ?

Si vous ne trouvez pas une application ou un outil, ou en cas de problème avec MagApp lui-même, utilisez **« Déclarer un incident »** ou **« Faire une demande »** : la DSI vous répond dans vos tickets.
